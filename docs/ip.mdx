# How to Join

![Borderra](../static/img/borderra-hero.avif)

The IP address to join Borderra is **join.borderra.com**

## Join Instructions

1. Open Minecraft **JAVA** Edition.
2. Click "Multiplayer".
3. Click "Add server".
4. Change "Server Name" to Borderra
5. Enter the IP **join.borderra.com** into the "Server Address" field. No port necessary.
6. Borderra has been added to your server list, double-click it to join.

## Troubleshooting

If you are having trouble joining the server, please make sure of the following:

- You entered the IP address in correctly. Try typing it out instead of copy and pasting.
- You are joining using Minecraft Java Edition. Bedrock Edition is **not** supported.
- You have purchased Minecraft from [minecraft.net](https://minecraft.net)
- You have a stable connection. If you do not, try lowering your render distance to the minimum.
- [Mojang authentication](https://isminecraftdown.com/) services are available
- Your DNS server supports SRV records (After entering IP, server does not show up as online). If not, [try changing your DNS servers to 1.1.1.1](https://developers.cloudflare.com/1.1.1.1/setup/windows/)
