# mcMMO Guide

![Borderra geopolitical Minecraft skill progression preview](/img/borderra-hero.avif)

Borderra uses **mcMMO** for skill progression. Mining, farming, fishing, fighting, movement, and crafting-related actions can level skills over time, giving long-term players progression without replacing towns, nations, gold, or diplomacy.

mcMMO rewards activity. The more a player works in a skill, the more that skill grows.

## Skills And Progression

Use individual skill commands to check levels, experience, and ability information.

```text
/mining
/woodcutting
/herbalism
/excavation
/fishing
/archery
/swords
/axes
/taming
/repair
/acrobatics
/alchemy
```

Use a question mark and page number for command help:

```text
/mining ? 1
/fishing ? 1
```

The in-game mcMMO help is the source of truth for active abilities, level requirements, and server balance settings.

## Skill Summary

Common mcMMO skills grow from normal gameplay:

- **Mining** - Break stone and ores.
- **Woodcutting** - Break logs and wood.
- **Herbalism** - Harvest crops and plants.
- **Excavation** - Dig dirt, sand, gravel, clay, and similar blocks.
- **Fishing** - Catch fish and treasure.
- **Archery** - Deal damage with bows and crossbows.
- **Swords** - Fight with swords.
- **Axes** - Fight with axes.
- **Taming** - Work with tameable animals.
- **Repair** - Repair damaged gear.
- **Acrobatics** - Survive falls and movement damage.
- **Alchemy** - Brew potions.

Skills give players reasons to specialize. A town with strong miners, farmers, builders, fishers, and fighters can support more projects than a town where everyone does the same job.

## Abilities

Some mcMMO skills include active abilities. Active abilities usually require the correct tool and a right-click action before using the tool normally.

Example flow:

1. Hold the correct tool.
2. Right-click to ready the ability.
3. Use the tool on the matching block or target.
4. Wait for the cooldown before using the ability again.

Some skills focus on passive benefits instead of active abilities. Passive benefits improve through normal skill leveling.

## Leaderboards

mcMMO rankings show who has invested time into different skills.

Useful ranking commands:

```text
/mctop
/mctop <skill>
/mcrank
/inspect <player>
```

Leaderboards are useful for finding specialists. Hire known miners for excavation, strong repair players for gear work, skilled fishers for rare catches, and experienced combat players for defense.

## Parties

mcMMO parties let players coordinate progression and communication.

Useful party commands:

```text
/party create <name>
/party
/party invite <player>
/party join <leader>
/party quit
/partychat
/pc
```

Parties work best for group mining, town projects, training sessions, and long resource trips.

## Borderra Tips

Use mcMMO as part of the geopolitical game instead of treating it as a separate grind.

- Level mining while supplying town banks and markets.
- Level herbalism while feeding residents and trade routes.
- Level fishing near ports and coastal towns.
- Level repair by supporting town gear and national projects.
- Level combat skills through defense, training, and organized fights.
- Use leaderboards to find workers, suppliers, and specialists.

A strong nation uses skilled players as infrastructure. The best skills are the ones that help towns, markets, and diplomacy work better.
